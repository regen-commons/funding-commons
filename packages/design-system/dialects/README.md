# Dialects

Each surface speaks the same language with its own emphasis. A dialect adds rules for one surface, and it never changes token values. If a dialect needs a new value, add it to [DESIGN.md](../../../DESIGN.md).

| Dialect | Surface | Status |
|---|---|---|
| [app.md](app.md) | The Weave installable web app | Applies from Phase 0 |
| [website.md](website.md) | regencommons.com public pages | Adoption is up to website maintainers |
| [desk.md](desk.md) | The steward desk | Adoption is up to website maintainers |
| [email.md](email.md) | Sign-in, weekly update and membership mail | Applies when email templates are written |
